# Test

Project skill: **Ian Xiaohei Illustrations** (`ian-xiaohei-illustrations`).

Agents should use [`.cursor/skills/ian-xiaohei-illustrations/`](.cursor/skills/ian-xiaohei-illustrations/) whenever Chinese article illustrations, 小黑配图, shot lists, or hand-drawn 16:9 explainer images are needed.

Upstream: [helloianneo/ian-xiaohei-illustrations](https://github.com/helloianneo/ian-xiaohei-illustrations)

## How to invoke

Ask the agent in Chinese or English, for example:

- 用小黑配图 skill 为下面这篇文章生成 4 张 16:9 正文配图
- 先不要生图，只出 shot list
- 为“……”这个判断生成一张小黑怪诞正文配图

Finished PNGs go to `assets/<article-slug>-illustrations/`.
